# LSS Logseq Plugin

LSS (Logseq Structured System) is a graph-object operating layer for Logseq.

## Features

- Entity creation
- Form creation
- Hierarchical relationships
- Parent-child graph modeling
- Template expansion
- Structured page generation
- Query-driven graph traversal

## Architecture

- registry.js
- parent_rules.js
- templates.js
- queries.js
- schema.js
- entity_engine.js
- form_engine.js
- ui_panel.js
- index.html

## Philosophy

Pages = durable graph objects
Templates = repeatable creation systems
Properties = relationships
Queries = graph traversal
